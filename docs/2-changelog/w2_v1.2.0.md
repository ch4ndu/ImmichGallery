# Changelog - Week 2, 09-08-2026, V. 1.2.0

**Release Date**: Week 2, 09-08-2026 at 23:08
**Version**: 1.2.0 (previously 1.1.0 in application version surfaces)
**Object**: release: ImmichGallery 1.2.0
**Code review**: `docs/3-code-review/CR_w2_v1.2.0.md` (Sol review, accepted-fix wave, and final gate -> APPROVED)

## Changes

- Expanded Search with Context, Filename, Description, and OCR text modes,
  selecting Immich Smart or Metadata Search before the request starts.
- Added a searchable multi-select People editor with authenticated face
  thumbnails, stable IDs, selected-first local filtering, atomic draft
  Cancel/Apply behavior, and direct applied-chip removal.
- Added Album, Tag/Untagged, camera make/model/lens, country/state/city, date,
  media/motion, Favorite, Not-in-album, visibility, and Rating/Unrated filters.
- Added adaptive Advanced Search editing through a Material bottom sheet below
  600dp and a bounded dialog on wider layouts, while preserving the existing
  justified result grid, pagination, viewer, and return-position behavior.
- Added live destination-scoped capabilities, preferences, Tags, and typed
  camera/location suggestions; People and Album options reuse their existing
  Room-backed list caches and synchronization UseCases.
- Added normalized submitted sessions, exact omitted-versus-null request
  encoding, stale option-request cancellation, retryable failures, and blank
  final-filter clearing that restores Explore without an unfiltered API call.
- Corrected lens suggestions to Immich's `camera-lens-model` wire value and
  sanitized suggestion-failure logging so throwables, URLs, response bodies,
  and camera/location dependency values are not written to local logs.
- Added 55 focused tests across request construction, endpoint dispatch,
  criteria normalization, option loading, picker presentation, ViewModel state,
  pagination, Person selection, direct removal, and sanitized diagnostics.
