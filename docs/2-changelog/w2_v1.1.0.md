## Changes

- Replaced the Search shell tab with Explore while retaining Immich smart and
  filename search, pagination, density settings, and viewer behavior.
- Added live owner-filtered Favorites with authenticated-user resolution,
  guarded sparse-page consumption, explicit retry progress, and an independent
  justified-row density setting.
- Added current-local-date On This Day Memories with year-labelled cover cards,
  live-only loading, supported-asset filtering, stable server ordering, and
  cover-origin viewer return behavior.
- Added read-only viewer-scoped stack discovery, explicit preflight states,
  retryable failures, and a nested viewer that preserves the base viewer and
  source-grid return target.
- Added Memories page progress that displays every fixed-slot dot when the row
  fits, continuously transfers emphasis during swipes, and uses segmented
  fractional progress when the complete dot row cannot fit.
- Preserved modal stack viewer state, made delegated TRIP runtime progress
  observable, and documented the new feature, architecture, cache, and viewer
  contracts.
